Each noise is evaluated on the CPU by the modules in src/noise/, the same code the self-check verifies, on a 256×256 crop at screen coordinate (1024, 1024). The result view accumulates frames 0 to the chosen frame, blurs the accumulation, and shows its error against the exact answer (0.5 for the value, the threshold t for the thresholded mask), amplified by the gain. Blue-noise textures are not included here; they are in the spatial results.

Notes. The Gaussian kernel is truncated at 3σ (the spatial analysis truncates at 4σ). Noises marked static ignore the frame index, so accumulation does not change them. The white noises draw an independent frame per index. "Aligned 8×8 tiles exactly stratified" counts tiles of the current frame whose 64 values fall one in each bin of width 1/64. The spectrum is the power of the current frame's values with the mean removed, on a log scale from 0.001× to about 30× the white-noise level, low frequencies at the centre.

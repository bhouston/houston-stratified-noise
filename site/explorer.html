Explorer

Each noise is evaluated on the CPU by the modules in src/noise/, the same code the self-check verifies, on a 256×256 crop at screen coordinate (1024, 1024). It opens on the regime these samplers are used in: exponential accumulation (α = 0.1, about 19 effective frames) over 64 frames with a σ = 1 blur; drag the frame slider to 0 for a single frame. The result view accumulates the chosen test function over frames 0 to the chosen frame, blurs the accumulation, and shows its error against the exact answer, amplified by the gain. With two or four values per pixel, each value gets its own seed and temporal step, and the second view plots one pixel's samples so the step behaviour is visible: choose the shared golden step to see the lockstep failure. The analytic R4 samplers are included so their lattice structure can be seen in the pattern and its spectrum. The downloaded blue-noise textures (FAST, STBN, Christoph Peters) are not included here; they are in the results.

Notes. The exponential accumulation ramps up like a TAA history after a reset: frame n since the reset is blended with weight max(1/n, α), so the first 1/α frames are an equally weighted running mean and later frames are the usual EMA. History resets whenever a setting that changes the frames is changed, and the frame slider always shows the result of accumulating from frame 0. The tables on the Results page measure the steady state (frames 128–255), which this ramp does not affect; the explorer's early-frame numbers are not comparable with them. The Gaussian kernel is truncated at 4σ, as in the spatial analysis. Noises marked static ignore the frame index, so accumulation does not change them, and they define only one value per pixel. The temporal steps apply to the noises that step in time by a Weyl sequence (%short%, hash + R_d, IGN + R_d, void-and-cluster + R_d); the others ignore them. The trade-off candidate is the optional four-value set from the step search, not the default. The white noises draw an independent value per pixel, frame and dimension. The pattern, threshold and spectrum views show the first value. "Aligned 8×8 tiles exactly stratified" counts tiles of the current frame whose 64 values fall one in each bin of width 1/64. The spectrum is the power of the current frame's values with the mean removed, on a log scale from 0.001× to about 30× the white-noise level, low frequencies at the centre.
